# Chess Combat

**Unity online multiplayer chess game · Unity · C#**

Chess Combat is a multiplayer chess game built in Unity. Players can jump into an online match or start a new local game, with full chess piece movement and move validation, player profiles, and a clean main menu and settings flow.

## Features

- **Online multiplayer** chess matches between players
- **New Game / local play** for a quick match on one device
- **Player profiles**
- **Main menu and settings UI**
- **Piece movement and move validation** so only legal chess moves are allowed
